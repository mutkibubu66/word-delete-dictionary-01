## The word

> moist

The one word to erase from the dictionary forever. It is the word in
English that makes a whole room flinch on contact — a perfectly
innocent adjective that somehow sounds like something it should not.
Nobody needs it: cakes are "tender", towels are "damp", soil is "wet".
Deleting "moist" loses nothing and spares everyone the shudder.

## Run it

```sh
python3 main.py
```

This writes the word (5 characters, one word) to `/output/entry.txt` —
valid UTF-8, inside the 1–77 character gate — and prints it to stdout.
Pure Python 3.13 standard library, no network access, deterministic:
every run writes the same word.
